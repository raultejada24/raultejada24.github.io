# raultejada24.github.io

Personal portfolio website showcasing my projects, skills, and professional profile.

## View Live

Visit: [https://raultejada24.github.io](https://raultejada24.github.io)

## Features

- **Developer-style intro** - Typing greeting, availability status and a code editor with switchable files
- **Command palette** - Press Ctrl/⌘+K (or tap the header button on mobile) to jump anywhere, copy my email or download the CV
- **Tech stack** - 40+ technologies with logos, filterable by area
- **Featured projects** - Four apps (including my bachelor's thesis, CadenceLab) with visual previews, plus more from GitHub
- **Why me** - My strengths as a test suite that runs and passes as you scroll
- **Education and languages** - My path shown as a CI/CD pipeline, plus CEFR language levels
- **Quick contact** - Copy my email in one click, LinkedIn, GitHub and the CV in English or Spanish
- **Light and dark themes** - Follows the system setting, with a toggle that remembers your choice
- **Responsive and accessible** - Works down to phone width and respects reduced-motion settings
